# No Safe Level — нет безопасного уровня

Мод для Fallout 4: Содружество остаётся опасным на любом уровне. В ванили к концу игры игрок
становится «ходячим танком»: враги почти не наносят урона. С модом сопротивление урону снижено на 25%, а
для урона врагов введены поправочные коэффициенты, так что бой на 50-м уровне ощущается как Корвега на
4-м. Одна настройка в MCM — **«Уровень угрозы»** 1–10 (5 — задуманный баланс, настроен под «Выживание»).

**Спойлер.** На странице Nexus механика намеренно не раскрывается. Здесь она описана полностью:
идея и расчёты — `ANALYSIS.md`, решения, результаты тестов в игре и формулы — `PLAN.md`.

## Как работает

- **Перк на игроке** (`NSL_Perk`, скрытый) — 95 записей точки «Mod Incoming Weapon Damage» (EP 36), по
  одной на **полосу урона**. Каждая умножает урон попадания на `1 + AV` своей полосы; при AV = 0 ничего не
  меняет. Полосы:
  - **weapon** — оружие `Fallout4.esm`, условие `GetIsID` цепочкой через OR на вкладке оружия атакующего;
  - **creature** — атаки существ с собственным уроном оружия (таракан, гуль, собака, горилла…):
    `GetIsID` оружия + диапазон `UnarmedDamage` атакующего. Урон такой атаки = урон оружия +
    `UnarmedDamage`, а у вариантов одного существа добавка разная (гули 0–90);
  - **unarmed** — атаки существ с уроном оружия 0 (коготь смерти, кротокрыс…), диапазон `UnarmedDamage`;
  - **fallback** — оружие DLC и модов (его нет в `NSL_KnownWeapons`), категории по ключевым словам
    `WeaponType*` из `Fallout4.esm`.

  Взрывчатка и всё, что бьёт через взрыв снаряда, не затрагивается: множитель перка лёг бы и на взрыв, а
  взрывы движок усиливает сверхлинейно. Смешанный урон (плазма) получает вторую запись — EP 94 с
  `EPIsDamageType(dtEnergy)` для энергетической части.
- **Скрипт** `papyrus/NSL/Main.psc` (квест `NSL_Quest`) раз в 3 с проверяет уровень, DR/ER, «Уровень
  угрозы», `NSL_Enabled` и множитель «Выживания» и при изменении пересчитывает AV всех полос. Для полосы с
  типичным уроном `P`:
  - нужный урон до брони `Q = max(K(L)·P, c·Пол(L))`: `K` — чтобы враг своего уровня убивал за столько
    же попаданий, что рейдер в Корвеге (0.89 на 4-м уровне … 1.76 на 80-м); `Пол = HP_эталон / 16` — без
    брони на «Выживании» 4 попадания; `c` — доля пола на попадание (автомат 0.3, дробина 1/n, огнемёт 0.1);
  - броня гасит на четверть меньше: `m_мод = 1 − 0.75·(1 − m)`;
  - «Уровень угрозы» умножает всё на `s = 2^((уровень − 5)/4)`;
  - атакам существ `K` не применяется: их урон и так растёт с уровнем варианта.

  Движок сам применяет броню, поэтому скрипт решает обратную задачу: во сколько раз умножить урон, чтобы
  ванильная формула выдала нужное. Для пуль множитель действует до брони, для энергоурона — после
  (коэффициент брони считается от базового урона оружия). `tools/sim.py` — то же на Python, с проверкой.
- **MCM** — один ползунок прямо на глобальную переменную `NSL_ThreatLevel` (`sourceType: GlobalValue`).

Всё, на чём это держится, измерено в игре тестовым плагином (`TEST.md`, результаты — в `PLAN.md`):
«Выживание» даёт ×2 до брони (ванильный `HC_DamageMultPerk`) и ×2 после (GMST); при DR 0 броня пропускает
100%; какие условия работают на вкладках атакующего и его оружия; из чего складывается урон атак существ.

## Требования

- Ничего, кроме игры: единственный мастер — `Fallout4.esm`, DLC не нужны. Плагин с флагом ESL.
- По желанию: Mod Configuration Menu (нужен F4SE) — для ползунка. Без него уровень угрозы 5, менять —
  `set NSL_ThreatLevel to N` в консоли.
- По желанию: Garden of Eden Papyrus Script Extender — только для отладочного лога.

Проверено на версии игры 1.10.163 (до Next-Gen). ESP и Papyrus одинаковы на всех версиях.

## Консоль

| Команда | Что делает |
|---|---|
| `set NSL_ThreatLevel to 7` | «Уровень угрозы» без MCM |
| `set NSL_Enabled to 0` | выключить мод (все множители 1); `1` — включить |
| `set NSL_Debug to 1` | писать множители полос и каждое попадание по игроку в `Data\NoSafeLevel\NoSafeLevel.log` |

## Сборка

Нужна установленная игра: полосы строятся из её файлов.

```
python tools/scan_weapons.py      # data\weapons.json, data\creatures.json (Fallout4.esm + DLC)
python tools/bands.py             # data\bands.json — полосы урона
python tools/gen_esp.py           # build\NoSafeLevel.esp (ESL, мастер — Fallout4.esm)
python tools/gen_mcm.py           # mod\MCM\Config\NoSafeLevel\config.json, mod\Interface\Translations\*
"<игра>\Papyrus Compiler\PapyrusCompiler.exe" papyrus ^
    -i="papyrus;<F4SE Scripts\Source>;<игра>\Data\Scripts\Source\User;<игра>\Data\Scripts\Source\Base" ^
    -o="build\scripts" -f="Institute_Papyrus_Flags.flg" -all
python tools/deploy.py            # в игру (оба Plugins.txt); --remove — убрать; --test — тестовый плагин
python tools/sim.py               # проверка математики и «попаданий до смерти»
python tools/gen_cover.py         # images\cover.png, images\banner.png для Nexus
```

`<F4SE Scripts\Source>` — исходники скриптов F4SE; `Data\Scripts\Source\User` должен содержать
`GardenOfEden3.psc`. Путь к игре — переменная окружения `FO4_PATH` (по умолчанию `D:\Games\Fallout 4`).

Тестовый плагин (`tools/gen_test_esp.py`, `papyrus/NSL/TestQuest.psc`, `CalibQuest.psc`) и разбор его
логов (`tools/analyze_test.py`, `tools/analyze_calib.py`) — см. `TEST.md`.
